# ComfyUI master workflow prompts

Use these prompts for the replacement portfolio images. Generate the artwork without text; the website supplies all headings and labels in HTML.

## Shared visual language

Isometric premium 3D operational infographic, clean product-design render, deep electric cobalt blue machinery, cyan illuminated edges, restrained polished gold connectors, small green status lights, realistic glass and brushed metal materials, precise readable hierarchy, soft studio rim lighting, generous negative space, isolated on pure solid black background #000000, centered composition, entire object visible, no cropping, square 1:1 canvas, production-ready asset for alpha removal.

Negative prompt: letters, words, captions, logos, watermarks, brand marks, tiny illegible UI text, people, hands, flags, religious imagery, temples, fantasy characters, excessive neon, rainbow palette, clutter, duplicated objects, broken geometry, warped screens, transparent checkerboard, grey background, gradient background, floor, room, landscape, crop, cut-off objects, motion blur, low detail.

## Homepage — four systems, one accountable foundation

Create one coherent isometric 3D portfolio map for Urban Explorer Labs. A compact electric-blue central control core distributes four clearly separated operational lanes, each with a unique physical metaphor: seller-order lane with chat terminal, catalog shelf, cart, payment review and receipt; campaign lane with brief intake, brand asset cabinet, production stages, human approval and channel delivery; content lane with idea intake, draft cards, image approval, weekly calendar and scheduled output; document lane with secure intake, scanner, source-linked evidence, deterministic checks, human decision console and audit export. Gold rails connect every lane to the central core but the lanes never merge their data. Include one visible human-control gate before every final output. Balanced horizontal composition, easy to understand at small website size. No text inside the render.

## LUYAGENT — chat to confirmed order

Create an isometric 3D order journey built as one continuous electric-blue conveyor. Seven distinct stations: Telegram-style conversation terminal represented only by chat bubbles, catalog and stock shelf, shopping cart with address card, COD or bank QR terminal, payment-evidence scanner, seller confirmation gate with a large gold human-control button, receipt printer and handoff tray. Gold rails preserve a visible connection from first message to final receipt. Use cyan active edges, green confirmed lights and one amber payment-review light. The seller gate must be visually dominant. No text or logos.

## KhmerADV — campaign command workflow

Create an isometric 3D agency campaign command line with separated brand containers feeding one selected campaign. Seven stations: campaign brief, copy direction, image production, brand composition, human approval, channel permission gateway, delivery and correction loop. Show different brand assets remaining in isolated glass cabinets, never mixed. A central campaign board connects stages with gold rails; approved output fans out to several abstract channel tiles only after a gold human-approval gate. Cobalt blue base, cyan edges, restrained orange accent for the selected campaign, green readiness lights. No text or logos.

## Hermes Post — idea to approved content week

Create an isometric 3D small-business content assistant. One glowing idea capsule feeds a drafting machine, then an image card station, a brand-voice review gate, a gold owner-approval console, and a weekly calendar board with five clean day slots leading to a scheduled-output tray. Make the sequence gentle, clear and approachable while preserving the same premium cobalt-blue, cyan and gold system language. The owner approval control must sit between creation and scheduling. Use green lights only for approved cards and amber for work awaiting review. No text or logos.

## KramOS — evidence-linked decision console

Create an isometric 3D compliance document review dashboard represented as a physical operational console. Left side: secure document intake and OCR scanner feeding a document queue with three unmistakable states using green verified, amber review and red missing-evidence indicators. Centre: selected source document under a gold magnifying lens, visible source-page link chain and deterministic rule module. Right side: department routing nodes, evidence chain, and a large human decision console with three distinct controls for approve, request evidence and recorded override. Finish with a locked audit-trail export drawer. Every finding remains physically linked by gold chain or rail to its source page. Cobalt blue body, cyan edges, restrained gold controls, no text or logos.

## Output settings

- Resolution: 1536 × 1536 or 2048 × 2048.
- Background: exact #000000, uniform corner to corner.
- Keep at least 12% empty margin around the full object.
- Export lossless PNG, then remove only the pure black background to alpha.
- Do not generate typography; add labels in React/CSS for accessibility and mobile clarity.
