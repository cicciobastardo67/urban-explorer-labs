# NotebookLM visual prompts for Urban Explorer Labs

Use NotebookLM Studio **Infographic** for website graphics. Choose **Landscape**, **Detailed**, **Professional**, and English unless specified otherwise. Download the final artifact as PNG; do not embed the NotebookLM viewer.

## Sources to add

Create one portfolio notebook plus one notebook per product. Add only verified material:

- Public website and product-page URLs.
- Product README and user guide.
- One workflow or architecture document.
- Screenshots of the real interface.
- A short approved positioning note.
- For KramOS only: verified Cambodian regulation sources.

Do not add secrets, `.env` files, databases, customer data, tokens, private keys or internal credentials.

## 1. Portfolio overview graphic

```text
Create a professional landscape infographic for the Urban Explorer Labs website titled “Four systems. One accountable foundation.”

Show one central foundation labelled “Private operations layer” connected to four clearly separated product lanes:
1. KramOS — evidence-first compliance review
2. KhmerADV — multi-brand campaign production
3. Hermes Post — simple content planning for shops and creators
4. LUYAGENT — chat sales and seller operations

For each lane show exactly three workflow stages and one human approval point. Make the differences between the products immediately understandable in five seconds.

Visual direction: pale mist-blue background, white operational panels, black editorial typography, cobalt-blue connectors and status signals, tiny green/amber/red status dots, thin blue-gray dividers. Clean enterprise interface, not a generic technology poster. No neon, gradients, robots, brains, floating AI icons, stock photography, fake customer logos, invented metrics or performance claims.

Use short labels only. Leave generous whitespace. Compose it so it can be cropped into a 16:9 website section without losing information.
```
